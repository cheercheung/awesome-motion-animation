# Security / 安全说明

This repository publishes resource links, descriptions, and original images. It does not distribute the listed tools or operate their services.

## What to report here

Report malicious or hijacked links, exposed secrets, unsafe repository automation, and other problems in this collection. Open a public issue only when it contains no exploit details, credentials, or personal information.

For sensitive reports, use GitHub's private vulnerability reporting entry under this repository's Security tab when available. If it is unavailable, use a contact method explicitly published on the maintainer's profile at https://github.com/cheercheung. Do not disclose a secret while seeking a contact route. No fixed response time is promised.

Report vulnerabilities in a linked tool through that project's own security policy. Review upstream installation instructions before running software.

## 中文说明

本仓库提供资源链接、说明与原创图片，不分发收录工具。可在此报告恶意或被劫持的链接、凭据泄露及仓库自动化问题。

不含敏感信息的问题可以提交公开 issue。敏感问题优先使用 Security 页中的私密漏洞报告入口（若可用），或维护者 GitHub 主页明确公开的联系渠道。不要公开凭据或利用细节。第三方工具漏洞请按上游项目的安全流程报告。

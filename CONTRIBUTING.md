# Contributing / 参与贡献

Help people find useful motion and animation projects. This is a curated resource collection; contributions should improve selection, accuracy, or usability.

## Suggest a resource

1. Search the existing list and issues for duplicates.
2. Use the resource issue template. Include the official public GitHub repository, a short concrete use case, the best category, and an official license/terms link.
3. Explain what the project adds to the collection. Prefer a maintained project with usable documentation and a clear motion/video purpose.
4. Disclose affiliations. Do not submit paid placement, tracking links, copied promotional claims, or unverified pricing/performance claims.

## Submit a pull request

1. Fork the repository and create a focused branch.
2. Update `data/projects.json`, `README.md`, and `README_zh-CN.md` together. Keep existing numbers and stable anchors intact; coordinate renumbering or category changes in an issue first.
3. Translate descriptions and licensing caveats faithfully. Preserve project names and official URLs. Check the license file itself; GitHub's detected license label can miss component-specific terms.
4. Verify relative links, category navigation, images, and English/Chinese parity. Preview both READMEs at desktop and narrow widths. Run `git diff --check`.
5. Open a pull request using the template. Link supporting sources and describe what you verified.

No package install or build step is needed to read or edit this documentation collection. Use any Markdown editor. Work on one correction or resource per pull request when practical.

## License and attribution

Do not copy upstream code, screenshots, logos, or documentation without checking their separate terms. All upstream projects retain their own licenses.

## 中文说明

欢迎补充资源、修正用途、更新许可信息与改进翻译。先检查重复项目，提交官方仓库、具体用途、建议分类和上游许可链接，并说明关联关系。

提交 PR 时同步更新中英文 README 与 `data/projects.json`，保留稳定编号和锚点。分类调整或编号变更请先开 issue 协商。核对上游完整许可，检查链接、图片与桌面/窄屏排版，再运行 `git diff --check`。

请只提交原创或有权分享的材料。原创整理内容采用本仓库 CC BY 4.0；上游代码、素材与品牌资产的许可保持独立。

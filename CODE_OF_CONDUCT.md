# Community Code of Conduct / 社区行为规范

We welcome contributors of all backgrounds. Keep discussion respectful, specific, and focused on making the collection useful.

- Critique claims and edits, not people. Provide evidence when correcting a description or license label.
- Respect identity, privacy, attribution, and other people's time.
- No harassment, hate speech, threats, sexualized attention, doxxing, spam, or undisclosed promotional placement.
- Do not post API keys, personal data, or private correspondence.

Maintainers may edit or remove harmful content, close disruptive threads, or limit participation. They should explain moderation decisions when doing so is safe and appropriate.

For ordinary moderation concerns, contact the maintainer through the contact options published on https://github.com/cheercheung. Do not put private allegations or personal information in a public issue. For security-sensitive material, follow SECURITY.md. No response-time guarantee is made.

请尊重不同背景的贡献者，围绕具体内容与证据讨论。禁止骚扰、歧视、威胁、泄露隐私、垃圾信息与未披露的推广。维护者可移除不当内容或限制参与。请通过维护者 GitHub 主页公开的联系渠道反映问题，不要在公开 issue 中发布私人信息。
